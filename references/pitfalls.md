# 坑位速查表（全部实测踩过，含解药）

## 渲染类

| 坑 | 症状 | 解药 |
| --- | --- | --- |
| 沙箱批量删除保护 | 渲染 1 秒即死，`SAFE_DELETE_BULK_CONFIRM_REQUIRED`；场景里设 `no_latex_cleanup`/`max_files_cached` 都拦不住 | `scripts/render_safe.py`：渲染进程内把 os.remove/unlink/os.rmdir/shutil.rmtree/Path.unlink 全部 no-op（缓存留着无害） |
| partial 缓存串味 | 换了同名图片素材（lay_*.png 等）渲染后画面没变，抽帧与旧版逐字节相同 | 每次渲染前把 `media/videos/<场景>` **改名移走**（不删），强制全量重渲 |
| 8fps 低画质时长偏长 | 低画质 152s、60fps 只有 142s | run_time 按帧粒度向上取整所致，**以 60fps 时长为准**，属正常 |
| 结尾字幕出画 | Act6 相机 `scale(0.93).move_to([0,0.4])` 后，TAG_Y=-4.02 的字幕在画面外 | 出画后的字幕改 `scale=0.93, center=[0,0.4]`（跟镜头走） |
| cwd 重置 | 每条命令后 shell 工作目录重置，from_image 找不到 assets | 每条命令显式 `cd 项目文件夹`；--media_dir 显式指定在项目内 |

## 素材类

| 坑 | 症状 | 解药 |
| --- | --- | --- |
| 贴片带灰调 | 特写里贴片像糊了块灰、方形边界可辨 | light 阈值 155+gamma1.3，排线晕染(灰120-200) alpha 全归零；贴片非透明像素应为数千级 |
| 全图压暗聚光 | 贴片孤悬纸上，边界明显 | 选择性聚光：FOCUS 0.8 单位内全实、远处 set_stroke(opacity=0.12)，恢复逐笔 set_stroke(1.0) |
| 贴片细线穿帮 | 切片内刘海是铅笔细线，与 2.4 宽墨线粗细不匹配 | 重描：眼窗深色笔画提取成独立图（双眼椭圆挖空），from_image 提取后用 adaptive_widths+Create 盖上去（z 高于贴片） |
| 切段静默失效 | 五官窗口里残留描摹笔画，眼睛被埋 | `cut_out_rectangles()`（反向 y 会报错）+ 切段后断言窗口内残留点数=0 |
| 石墨杂痕擦不掉 | 按笔画长度过滤后画面仍有背景短痕 | 淡痕连成长链，长度过滤无效 → **按区域擦**：人物蒙版膨胀 60px 之外 alpha 全清 |
| 人物多边形白晕 | 上色阶段人物周围有白色光晕圈，等 full 才消失 | 余色层(lay_bgrest)全图兜底认领（不再限 bg），覆盖率拉到 100% |
| 色层变黑剪影 | 上色幕出现黑色色块 | 色层必须带原图 RGB（alpha 条件掩膜），不是黑色剪影 |
| 色层覆盖不全 | 人物蓝与背景蓝互相泄漏、中间调没人认领 | 人物多边形蒙版 + HSV 条件（空间 AND 色彩）+ 排他化认领（先皮肤/金/红，再蓝/白/深，火焰辉光全图生效最后兜底） |
| 上色像贴纸 | 每层一上来就是全饱和度，一块一块蹦 | 浸润式：full 32% 淡彩预乘打底 → 分区层依次加深 → full 定妆（参考星辉魔女观感） |

## 流程纪律

1. **任何提取参数调整，先出静态笔画预览再数笔数**（预览在纸色底上看）。
2. 每轮改动先低画质全片自检（抽帧看白描/特写/上色/结尾四段），过了再 1080p60。
3. **不经用户明说"通过"，绝不覆盖已交付视频与源码**——修订版一律新文件名（v2/v3/v4…）；
   用户明确说删的才删（走废纸篓，Finder 自动化常被 TCC 拦，用 `mv ~/.Trash/`）。
4. npz 缓存：0.1.1 有内容校验，但提取异常时先删 `<图>.strokes.npz` 再试。
5. 贴片/重描源生成后，先合成纸色底检查图人工过目，再进渲染。
